01
CORE VIEW

核心结论

AI 不替代研究判断。它真正的价值，是把信息收集、证据组织、反方验证和持续跟踪变成可审计的工作流。

01

先定义问题，再让 Agent 收集信息。没有研究问题的 Agent 只会生产更多看似完整的摘要。

02

证据要分层：公司披露、行业数据、媒体信息和模型推断不能混在一起，输出必须保留来源。

03

反方观点与证伪指标应成为固定步骤，而不是写完结论后的补充段落。

04
VALUATION

估值 / 定价框架

Agent 评估框架

不只用“回答像不像人”评估 Agent，而是从准确性、可追溯性、覆盖度、成本和时延五个维度建立验收标准。

01

事实准确性

抽样核对关键数字、时间与主体，区分事实、推断和观点。

注意 · 单次演示通过不代表稳定可用。
02

可追溯性

要求每条关键证据附来源、时间和原文位置。

注意 · 有来源不等于来源可靠。
03

反方覆盖

检查 Agent 是否主动寻找反例和证伪条件。

注意 · 形式上的反方段落不等于真正验证。
04

成本与时延

记录完成任务所需的模型调用、人工复核和时间。

注意 · 效率提升不能以牺牲准确性为代价。

05
RISKS & BEAR CASE

风险与反方观点

幻觉与错误归因

模型生成不存在的数字、来源或因果关系，且表达得非常确定。

过时数据

引用旧闻或过期财报，导致结论建立在失效信息上。

来源偏差

只检索容易获得的媒体信息，忽略公告、原始数据和反方证据。

自动化偏见

使用者因为输出结构完整而降低复核标准。

反方观点 / BEAR CASE主动寻找不利证据
  • Agent 可能提高信息处理效率，却降低研究深度。若问题定义不清，输出只会更快地偏离重点。
  • 可追溯不等于正确。来源本身可能有偏差，模型也可能正确引用却错误推理。
06
FALSIFICATION

证伪指标

如果以下条件出现，应下调当前结论的置信度，而不是为原有观点寻找解释。

  1. 01

    关键结论无法复现，或同一问题多次运行给出互相矛盾的事实。

  2. 02

    证据链缺失，无法定位原始来源。

  3. 03

    人工修正率随着使用深入持续上升，说明流程并未真正提效。
